> _"The only way to learn a new programming language is by writing programs in it."_

Welcome to the **Introduction to C++** series! This is a beginner-friendly, chapter-by-chapter guide to learning C++ from scratch. Below you'll find all chapters listed in order — start from Chapter 1 and work your way through.

---

## Chapters

### [Chapter 1: History & Philosophy](/cpp/history-philosophy/)

Learn about the history, philosophy, popularity, and application areas of the C++ programming language.

### [Chapter 2: Getting Started](/cpp/getting-started/)

Why learn C++, how to download and set up your IDE, compiler, and debugger for C++ development.

### [Chapter 3: Hello World & I/O](/cpp/hello-world/)

Your first C++ program, understanding I/O streams, comments, and the cout output stream.

### [Chapter 4: Types & Variables](/cpp/types-variables/)

Fundamental C++ types (bool, char, int, double, void), type modifiers, and variable declaration, definition, and initialization.

### [Chapter 5: Operators & Input](/cpp/operators-input/)

C++ assignment, arithmetic, compound assignment, increment/decrement operators, and standard input with cin.

### [Chapter 6: Arrays, Pointers, References & Strings](/cpp/arrays-pointers-strings/)

C++ arrays, pointers, null pointers, dereferencing, references, and introduction to std::string.
