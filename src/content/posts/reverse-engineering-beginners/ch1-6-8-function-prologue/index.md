# CH1.6 - CH1.8 - Function Prologue and Epilogue

## Function Prologue

The function prologue sets up the stack frame for a function:

```asm
function_name:
    push rbp           ; Save old base pointer
    mov rbp, rsp       ; Set up new base pointer
    sub rsp, N         ; Allocate space for local variables
```

### Why We Need It

1. **Preserve caller's stack frame** - Save RBP so we can restore it later
2. **Create new stack frame** - Set up our own reference point
3. **Allocate local variables** - Make room on stack

### Stack Layout

```
Higher addresses
┌─────────────────┐
│  Function args  │
├─────────────────┤
│  Return address │ ← RSP after CALL
├─────────────────┤
│  Saved RBP      │ ← RBP points here
├─────────────────┤
│  Local var 1    │ [RBP-4]
├─────────────────┤
│  Local var 2    │ [RBP-8]
└─────────────────┘
Lower addresses
```

## Function Epilogue

The epilogue cleans up and returns:

```asm
    mov rsp, rbp       ; Deallocate local variables
    pop rbp            ; Restore caller's base pointer
    ret                ; Return to caller
```

Or equivalently:

```asm
    leave              ; mov rsp, rbp + pop rbp
    ret
```

## Optimization: Frame Pointer Omission

With `-fomit-frame-pointer`, the compiler skips RBP:

```asm
function:
    sub rsp, 16        ; Allocate directly
    ; ... function body ...
    add rsp, 16        ; Deallocate
    ret
```

This frees up RBP as an extra general-purpose register.
